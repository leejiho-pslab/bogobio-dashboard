## 4. 사용자가 직접 해야 할 일 (우선순위 순)
1. **텔레그램 연결** (마지막 단계로 두기로 함): Apps Script 편집기에서 `setSecrets('대시보드비밀번호','봇토큰','채팅ID')` 1회 실행 → 다음 날 08:00부터 자동 발송.
2. **월 목표 입력**: 시트 '월목표' 탭에 월별 채널 목표(원) 입력 → 대시보드·텔레그램에 달성률 표시.
3. **자사몰 매출에 네이버페이 결제분 포함 여부 결정**: 포함(현재) / 제외(엑셀 방식). 제외로 바꾸면 시트 코드 1줄 수정으로 가능.
4. **제품마스터 이름 통합**: 시트 '제품마스터' 탭 '표준제품명'을 같은 제품끼리 같은 이름으로 수정(예: "산삼비책진 더 블랙 1박스"로 통일). 저장 즉시 대시보드에 반영.
5. **SSG 수집 재개**: 크롬 SSG 탭의 확인창 닫기 → "확인했어" 전달.
6. **국군복지몰·공구·오프라인**: 관리자 사이트가 있으면 주소 전달, 없으면 담당자가 구글폼으로 입력(판매일마다).
7. **매출수집 스킬 저장 + 실행 시각 결정**: 07:40 권장(자동 수집 3개가 끝난 뒤, 08:00 발송 전). 매일 실행하려면 그 시각에 **컴퓨터와 Claude 앱이 켜져 있어야** 외부몰 웹 수집이 됨.
8. **쿠팡 키 재발급(2026-12-27 전)**: Wing → 판매자정보 → 추가판매정보 → OPEN API 키 재발급 → 서버 `~/bogobio/config.json`의 cp_access/cp_secret 교체 + 채널톡에도 새 키 입력.
9. **불일치기록 9건 확인**: 엑셀 내부 차이. 어느 쪽이 맞는지 담당자 확인 후 '월별실적_과거' 수정.

## 5. 채널별 집계 기준 (대시보드 하단 표와 동일)
- **공통**: 결제(입금 확인)된 날짜에 매출. 취소·반품은 **처리 완료일**에 차감. 순매출 = 결제금액 − 취소금액 − 반품금액. 개인정보는 저장하지 않음.
- **스마트스토어**: 상품주문별 총 결제금액(할인·포인트 반영 후, 배송비 포함). 취소=취소완료일, 반품=반품완료일, 교환=요청일(수량만).
- **자사몰**: 주문 최초 결제금액(상품+배송비−쿠폰·회원·적립금·예치금). 원화 상점(1·2번)만. 네이버페이 결제분 포함. 결제된 주문의 취소만.
- **쿠팡**: 판매가×수량 − 판매자 부담 할인(쿠팡 부담 할인 제외 안 함). 서버는 원본만 가져오고 계산은 시트가 함('쿠팡원본' 탭 보관 → 계산식 변경 시 `cpReparse` 로 재집계).
- **G마켓/옥션**: 입금확인일 기준 구매자 결제금액. **11번가·롯데ON**: 판매가(플랫폼 부담 할인 전). **아난티**: 회원 할인 후 판매금액. **SSG**: 위수탁 정산 상세(순판매액, 월 마감 후 확정).
- **과거 월별(2025-01~2026-09)**: 엑셀 월별집계. 원장 일별이 있는 달·채널은 원장으로 교체. 외부몰은 몰별 수집이 끝날 때까지 엑셀 합계가 크면 엑셀 유지.
