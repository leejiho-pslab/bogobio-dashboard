# 구글 시트 자동화 설치 가이드 (1회, 약 10분)

준비물: 구글 계정, 텔레그램 앱. 비용 0원.

## 1. 구글 시트 만들기
1. https://sheets.new 접속 → 새 시트가 열림
2. 왼쪽 위 제목을 `보고바이오_채널현황_원장` 으로 변경

## 2. 코드 붙여넣기
1. 메뉴 **확장 프로그램 → Apps Script** 클릭
2. 열린 편집기에서 기존 내용(`function myFunction(){}`)을 모두 지우고, `Code.gs` 파일 내용 전체를 붙여넣기
3. 위쪽 💾(저장) 클릭

## 3. 최초 설정 실행
1. 편집기 상단 함수 선택 상자에서 `setup` 선택 → **▶ 실행**
2. "승인 필요" 창 → **권한 검토** → 계정 선택 → "확인되지 않은 앱" 화면이 나오면 **고급 → (프로젝트명)(으)로 이동** → **허용**
3. 1분 정도 뒤 "설정 완료" 알림. 시트에 `원장·채널마스터·월목표·설정·월별실적_과거·불일치기록` 탭과 **입력용 구글폼**이 자동 생성됨
   - 폼 주소: `설정` 탭의 `FORM_URL` 칸 (담당자에게 이 주소를 공유)

## 4. 텔레그램 봇 만들기 (3분)
1. 텔레그램에서 `@BotFather` 검색 → `/newbot` → 봇 이름(예: 보고바이오 리포트) → 아이디(예: `bogobio_report_bot`)
2. 받은 **토큰**(숫자:영문 긴 문자열)을 복사
3. 보고를 받을 **그룹방**을 만들고 봇을 초대 → 그룹에서 아무 메시지나 1개 전송
4. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 접속 → `"chat":{"id":-100xxxxxxxxx` 의 숫자(마이너스 포함)가 **채팅 ID**

## 5. 비밀번호·토큰 저장
1. Apps Script 편집기에서 맨 아래에 임시로 한 줄 추가:
   ```
   function _once(){ setSecrets('대시보드비밀번호', '텔레그램토큰', '채팅ID'); }
   ```
2. 함수 선택 `_once` → ▶ 실행 → 완료되면 **이 줄을 삭제하고 저장** (비밀번호는 코드에 남지 않음)

## 6. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → ⚙️ 유형 선택 → **웹 앱**
2. 설명 `v1`, **실행 사용자: 나**, **액세스 권한: 모든 사용자** → **배포**
3. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해서 Claude에게 전달
   → Claude가 대시보드에 연결하고 재배포합니다

## 7. 확인
- 브라우저에서 `웹앱URL?action=ping` 접속 → `{"ok":true,...}` 가 보이면 정상
- 구글폼으로 아무 채널 1건 입력 → `원장` 탭에 1행 추가되는지 확인
- 다음 날 08:00에 텔레그램 데일리가 오는지 확인

## 운영 중 변경
- **비밀번호 변경**: 5번 절차를 다시 실행 (대시보드 쪽 수정 불필요)
- **보고 시각 변경**: `설정` 탭 `REPORT_HOUR` 숫자 수정 (다음 날부터 적용)
- **월 목표 입력**: `월목표` 탭에 채널별 금액 입력 → 대시보드·텔레그램에 달성률 자동 표시
- **코드 업데이트**: Apps Script에 새 `Code.gs` 붙여넣기 → 저장 → **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** (URL은 그대로 유지됨)

## 자주 묻는 문제
- 폼 제출했는데 원장에 안 들어감 → Apps Script **트리거** 메뉴(⏰)에 `onFormSubmit_`이 있는지 확인. 없으면 `setup` 다시 실행
- 텔레그램이 안 옴 → 봇이 그룹에 있는지, 채팅 ID가 마이너스 포함 그대로인지 확인. 편집기에서 `sendDaily_` 직접 실행해 오류 확인
- 대시보드에서 "비밀번호가 맞지 않습니다" → 5번에서 저장한 비밀번호와 동일한지, 배포가 "모든 사용자" 액세스인지 확인
